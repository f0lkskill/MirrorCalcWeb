「使用说明」三步上手 · 结果怎么来的 · 取整规则

一、三步上手

镜息演算 —— 把一枚硬币的威力、乘区、追伤拆开算清楚，再放回整套循环里看收益。

  1. 填技能参数 —— 硬币数量、基础威力、硬币威力、攻击容量、攻击等级，照技能描述直接抄。
  2. 填硬币明细 —— 有几枚硬币就填几行：呼吸法强度、单币第二乘区、单币硬币威力、终币特殊威力（没有就留 0）。
  3. 读结果 —— 顶部「计算结果」实时刷新；想核对过程就展开下面「逐硬币计算过程」。
浅蓝 是你填的， 浅绿 是自动算的， 浅橙 是汇总结果。 改动任意一格，全部结果立即重算。

二、循环数据：怎么衡量一个人格

循环数据是手动录入区，用来记录一整套技能（6 回合 / 6 次技能）的总伤害。三条循环分别对应实战中的三个阶段：

循环阶段用来衡量什么
第一循环启动轮 关卡开始的前 6 回合。反映人格的启动速度与前期实力 —— 需要攒充能、叠层数才能发力的技能，这一轮会明显偏低。
第二循环启动后 启动完成后再打一轮 6 回合。大部分人格式此进入常态输出，最能代表实战水平。
极限循环理论上限 吃满全部加成时的一轮总伤。实战几乎不可能达成，仅作上限参考。
两轮循环总和 = 第一循环 + 第二循环，是横向对比人格整轮收益最实用的一个数：它把「启动慢」和「上限高」两件事合在一起看。

三、各版块填什么

版块说明
技能参数技能本身的固有数值。其中「最终基础威力」「最终硬币威力」「威力总值」是自动算出的。
全局设置对本技能所有硬币生效的开关：必定暴击、是否重投、技能第一/第二乘区。
硬币参数逐枚硬币的数值。硬币 1–9 对应技能的多段攻击，重投 1–9 对应重投产生的额外段。
逐硬币计算过程把每枚硬币的中间量全部摊开，用来定位「差 1 点伤害是哪一步造成的」。
未启用的行会自动隐藏：「硬币数量」决定启用前几枚硬币；「是否重投 = 是」+「重投次数」决定启用前几行重投。

四、结果是怎么算出来的

下面把每一步写清楚。所有名称都与界面上的标签一致，你可以对着输入框逐项验算。

点开下面每一项即可查看对应的算式与说明。

基础数值
攻/防等级差值 = 攻击等级 + 攻击等级加成 − 敌方等级 最终基础威力 = 向下取整( 基础威力 + 终础威力加成 + 反击加成 ) 反击加成 = 不可拼点反击 = 是 ? 攻/防等级差值 ÷ 3 : 0 最终硬币威力 = 硬币威力 + 硬币威力加成 威力总值 = 基础威力 + 终础威力加成 + 最终硬币威力 × 硬币数量
乘区（暴击与等级差都在这里）
暴击部分 = 必定暴击 = 是 ? 0.2 : MIN( 呼吸法强度 × 5% × 0.2, 0.2 ) 等级差修正 = 攻/防等级差值 ÷ ( |攻/防等级差值| + 25 ) 分母取绝对值，结果恒落在 −1 到 1 之间 单币第一乘区 = 四舍五入2位( 暴击部分 + 技能第一乘区 + 等级差修正 )
呼吸法强度 20 层即封顶：暴击部分最高只有 0.2，此时再叠呼吸法不再提升伤害。
必定暴击 = 是 时暴击部分恒为 0.2，呼吸法强度完全失效。
单枚硬币的伤害
不计算追伤伤害 = 向下取整( ( 最终基础威力 + 最终硬币威力 × N + 截至本行Σ单币硬币威力 + 截至本行Σ终币特殊威力 ) × ( 1 + 技能第一乘区 + 单币第一乘区 ) × ( 1 + 技能第二乘区 + 单币第二乘区 ) × 攻击容量 ) 追伤数值 = 是否追伤 = 是 ? 向下取整( 不计算追伤伤害 × 追伤系数 ) : 0 伤害数值 = 向下取整( 不计算追伤伤害 + 追伤数值 + 固定追伤 × 攻击容量 )
「不计算追伤伤害」最低为 1：边狱巴士的技能除非明确写了「不造成伤害」，否则至少会打出 1 点。 因此这一项以 1 为下限取整。
N 是这枚硬币在技能中的序号：硬币行 N = 1…9；重投行 N = 硬币数量 + 重投序号。
「截至本行Σ」是从第 1 行累加到当前行为止（含当前行）。
注意固定追伤要乘攻击容量，而追伤数值不乘。
总伤害与拼点点数
总伤害 = Σ伤害数值（全部已启用的硬币与重投） 拼点点数 = 不可拼点反击 = 是 ? 0 : 向下取整( 基础威力 + 终础威力加成 + 最终硬币威力 × 硬币数量 + 攻/防等级差值 ÷ 3 + 拼点威力加成 + ( 重投参与拼点 = 是 ? 最终硬币威力 × 重投次数 : 0 ) + Σ单币硬币威力( 已启用的硬币行 ) + ( 重投参与拼点 = 是 ? Σ单币硬币威力( 已启用的重投行 ) : 0 ) )
拼点点数只累加「单币硬币威力」，不含「终币特殊威力」。
重投行的单币硬币威力只有在「重投参与拼点 = 是」时才计入；否则重投只影响伤害，不影响拼点。
另外它用的是原始的「基础威力 + 终础威力加成」，而不是已经取整过的「最终基础威力」—— 这是它和伤害公式的一处细微差别。

五、参数扫描

想知道「呼吸法叠到多少层才封顶」「敌方等级差 5 级会掉多少伤害」，不用一个个手改 —— 选好参数和区间，点「开始扫描」即可。

  • 扫描会在当前配置的基础上逐点重算，结果只是推演，不会改动你填的任何数值。
  • 曲线上的红点是最佳取值；表格里「持平」表示这一步相比上一步没有变化。
  • 下方会自动给出结论，例如「呼吸法超过 20 之后伤害不再增长」。
「呼吸法强度」会同时作用于全部硬币；「硬币数量」会自动取整并按 0–9 截断。

六、取整规则

  • 乘区：只有「单币第一乘区」会四舍五入保留 2 位小数；技能第一/第二乘区、单币第二乘区、呼吸法强度都按你填的原值参与计算，不再取整。
  • 伤害：一律向下取整（例如 23.9 记为 23）。
  • 顺序：先算乘区并取整 → 再相乘 → 最后对伤害向下取整；追伤数值单独向下取整一次。
边狱巴士最小的加成单位是 1%，而第二乘区由你手动填写，本身就已经是整齐的数值，所以不额外取整也不会产生误差。

八、常见疑问

点开对应条目查看解答。

网页算出来和别处差 1 点？
多数是浮点尾数导致的取整方向差异。展开「逐硬币计算过程」表，对照「取整前伤害」与「取整损失」两列 —— 如果「取整前伤害」是 23.0000 这类贴着整数的值，说明它本来就在边界上，本工具会按真实小数处理。
档案存在哪里？会丢吗？
保存在本机浏览器的 localStorage，不会上传任何服务器。清理浏览器数据会连同档案一起删除， 重要档案请用「导出备份」存成 JSON 文件。
