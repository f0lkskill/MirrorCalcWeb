# MirrorCalcWeb
《边狱巴士》的单文件离线技能伤害计算器。双击 HTML 即可用，无外部依赖、无需联网。      计算逐枚硬币的伤害、拼点、追伤    用「第一循环 / 第二循环 / 极限循环」三组 × 6 回合评估人格强度    循环模式：逐回合记录，自动存档    存档文件夹管理 + 参数扫描 + 导入导出
